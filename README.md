# Tweet Translator

**Tweet Translator — Axiom Twitter Translator и X Translator для торговых терминалов.**

Расширение переводит посты и твиты X/Twitter при наведении курсора в Axiom Trade, GMGN и Padre. Перевод показывается рядом с оригиналом и повторяет его внешний вид, изображения и прокрутку.

Расширение не совершает сделки, не подключается к кошельку и не читает пароли или cookies.

## Скачать и установить

Собирать проект и устанавливать Node.js не нужно. Готовое расширение уже находится в папке [`extension`](extension):

1. Нажмите зелёную кнопку **Code**, затем **Download ZIP**.
2. Распакуйте скачанный архив репозитория.
3. Откройте в Chrome страницу `chrome://extensions`.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите папку **`extension`** внутри распакованного репозитория. В ней находится `manifest.json`.
7. Обновите уже открытую вкладку Axiom, GMGN или Padre.

Не выбирайте корневую папку проекта — Chrome нужно указать именно папку `extension`.

## Возможности

- перевод твитов при наведении;
- поддержка Axiom, GMGN и Padre;
- перевод основного и цитируемого твита;
- копирование всего перевода одним нажатием;
- синхронная прокрутка оригинала и перевода;
- русский и английский интерфейс в зависимости от языка браузера;
- 21 популярный язык перевода;
- русский язык перевода по умолчанию;
- параллельный перевод через Google, MyMemory, LibreTranslate/Argos, Lingva и Apertium без API-ключей;
- повторный перевод кнопкой `↻` без использования кэша.

Подходит для запросов: Axiom Twitter translator, Axiom Trade translator, X translator, Twitter translation Chrome extension, GMGN translator и Padre translator.

## Сборка из исходников

Этот раздел нужен только разработчикам:

```bash
npm install
npm run build
```

После сборки готовое расширение появится в папке `extension`. Эта папка хранится в Git, поэтому после изменения исходников её также нужно обновить командой `npm run build`.

## Использование

1. Откройте Axiom, GMGN или Padre.
2. Наведите курсор на значок или ссылку твита.
3. Дождитесь появления оригинального окна.
4. Перевод появится рядом с ним автоматически.

Окно перевода остаётся открытым столько же, сколько оригинал. Прокрутка обоих окон связана, даже если переведённый текст длиннее исходного.

Курсор можно свободно переводить между оригиналом и переводом: обе карточки считаются одной областью наведения. Чтобы скопировать основной и цитируемый перевод, нажмите метку **«Перевод ⧉»** в верхней части карточки.

## Настройки

Нажмите на значок Tweet Translator на панели Chrome. В настройках можно:

- включить или выключить расширение;
- отдельно включить Axiom, GMGN и Padre;
- выбрать язык перевода;
- отдельно включить или выключить Google, MyMemory, LibreTranslate/Argos, Lingva и Apertium;
- подключить собственный backend-прокси.

«Язык интерфейса» меняет подписи самого расширения. По умолчанию выбран режим «Как в браузере»: для русского Chrome используется русский интерфейс, для остальных — английский.

«Язык перевода твитов» — отдельная настройка. Она определяет, на какой язык переводить содержимое твитов; по умолчанию выбран русский.

## Если перевод не появился

Попробуйте по порядку:

1. Убедитесь, что расширение и нужная платформа включены в настройках.
2. На странице `chrome://extensions` нажмите кнопку обновления расширения.
3. Обязательно перезагрузите вкладку Axiom, GMGN или Padre.
4. Повторно наведите курсор на твит.
5. Нажмите `↻` в карточке, чтобы заново запросить перевод без кэша.

После каждой новой сборки необходимо обновить расширение и вкладку сайта. Старый код, уже загруженный во вкладку, автоматически не заменяется.

## Конфиденциальность

Все бесплатные публичные сервисы включены по умолчанию. Запрос отправляется им одновременно;
первый пригодный перевод используется, а остальные запросы отменяются. Каждый сервис можно
отключить в настройках. Собственный сервер выключен, пока пользователь не включит его и не
укажет URL.

Перед переводом расширение локально защищает ссылки, `@username`, `#hashtag`, тикеры,
адреса Solana/EVM, числа, emoji и термины из редактируемого криптословаря. Подробнее:
[политика конфиденциальности перевода](docs/PRIVACY.md).

Расширение берёт только текст видимого твита и отправляет его всем включённым сервисам перевода.

Google может временно ограничить частоту запросов или изменить этот endpoint. Для полностью контролируемой работы можно подключить собственный HTTPS backend-прокси в настройках.
