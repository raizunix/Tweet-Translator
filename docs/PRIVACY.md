# Конфиденциальность перевода

Tweet Translator обрабатывает только текст твита, popup которого пользователь открыл наведением. Расширение не переводит скрытые твиты заранее, не читает кошелёк, пароли или cookies и не перехватывает глобально `fetch`, XHR либо WebSocket.

## Кому передаётся текст

- Google Translate — основной сервис перевода.
- MyMemory — необязательный резерв, выключенный по умолчанию.
- Собственный сервер — необязательный резерв, выключенный по умолчанию и используемый только с URL из настроек.

Сервисы вызываются строго последовательно. MyMemory получает текст только после окончательной ошибки Google и только если пользователь включил MyMemory. Собственный сервер вызывается последним и только если он включён. Один запрос никогда не отправляется нескольким сервисам одновременно.

Перед отправкой расширение заменяет ссылки, имена пользователей, хештеги, тикеры, адреса кошельков, числа, emoji и выбранные криптотермины техническими маркерами. После перевода исходные фрагменты восстанавливаются локально.

Результаты временно хранятся только в ограниченном кэше памяти страницы и исчезают после её закрытия или обновления. Тексты переводов не сохраняются в `chrome.storage`.
