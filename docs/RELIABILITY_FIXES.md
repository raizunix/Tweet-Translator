# Исправления надёжности — 7 сентября 2026

- При повреждении маркеров движком переводятся текстовые фрагменты, а защищённые значения
  собираются локально. Полностью защищённые сообщения не отправляются в сеть.
- Исходный язык определяется Chrome по исходному тексту. Неуверенное определение не подменяется
  английским: сервисы с автоопределением продолжают работу, TartuNLP и Apertium пропускаются.
  Для TartuNLP, Apertium и LibreTranslate проверяются объявленные языковые пары; MyMemory
  получает явный язык либо `autodetect`. Уверенно распознанный неправильный язык ответа отклоняется.
- Ответ каждого зеркала проверяется на сохранность маркеров и неизменённый оригинал до победы
  во внутренней гонке. Повреждённый ответ не исключает остальные зеркала.
- Таймауты и отмена охватывают чтение тела ответа. Ожидание завершается и для адаптера,
  который игнорирует AbortSignal. Сигнал отмены передаётся через runtime в service worker.
- HTTP-запросы публичных провайдеров проходят через общую очередь service worker: до шести
  одновременно, до двух на origin, интервал старта 250 мс. Очередь ограничена ста ожидающими
  запросами. При 429 учитываются обе формы Retry-After; другие вкладки также соблюдают паузу.
  Неподдерживаемые пары, ошибки авторизации и квоты не запускают общие повторы Translator;
  для временных сбоев остаются повторы со случайной добавкой к задержке.
- Основной твит и цитата показываются независимо; повтор отдельного блока сохраняет остальные
  результаты. Копируются только успешно переведённые блоки в исходном порядке.
- Устаревшая операция не перезаписывает кэш и не удаляет pending новой операции.

Закрытие карточки **не отменяет перевод**: при повторном открытии используется тот же pending
запрос или готовый кэш. Проигравшие провайдеры и просроченные запросы отменяются.

Контент-скрипт дополнительно собирается как самостоятельный IIFE, чтобы общие модули ошибок,
таймаутов и проверки результатов не создавали запрещённые ESM-импорты в manifest content script.

Регрессии находятся в `tests/unit/reliability.test.ts`, `request-scheduler.test.ts`,
`free-provider-reliability.test.ts`, тестах Translator/Overlay и браузерном сценарии повторного
открытия карточки. Сетевые ответы в регрессиях управляемые: это проверка логики расширения,
а не обещание доступности внешних сервисов. Снимки и скрипты `docs/audit-2026-09-06` относятся
к состоянию **до исправлений**; старый probes.ts намеренно воспроизводил прежние дефекты.

Разбиение на текстовые фрагменты — резервный режим и может ухудшать связность предложения.
Автоопределение коротких и смешанных сообщений может быть неуверенным. Новые облачные API
и локальная модель в этот набор исправлений не добавлялись.
