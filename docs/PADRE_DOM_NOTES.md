# Padre DOM notes

Проверено на `https://trade.padre.gg` в авторизованной вкладке через Chrome DevTools Protocol.

- Триггер — ссылка на конкретный статус `x.com/.../status/...`.
- Поисковые и профильные ссылки X игнорируются.
- Загруженная карточка твита рендерится в portal-root с `role="tooltip"`.
- Визуальная карточка находится в первом дочернем элементе tooltip.
- Основной текст имеет крупный шрифт, цитируемый твит — 13px; адаптер Padre передаёт этот локальный порог общему структурному детектору.
- Прокручиваемая область определяется по вычисленному `overflow-y`, без зависимости от MUI-классов.

Сгенерированные классы Material UI не используются как селекторы.
