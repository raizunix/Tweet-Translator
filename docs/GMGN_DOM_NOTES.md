# GMGN DOM notes

## Подтверждённая стратегия

Адаптер проверен в авторизованной GMGN-сессии через Chrome DevTools Protocol.

- Триггер: ссылка `x.com`/`twitter.com` на конкретный `/status/`; ссылки на Community и поиск игнорируются.
- Popup: доступный `[role="tooltip"]`, который GMGN позиционирует внутри portal wrapper.
- Загрузка: пустой skeleton не клонируется; адаптер ждёт появления читаемого текста через общий `MutationObserver`.
- Контент: основной и цитируемый твиты определяются структурно по геометрии и вычисленным стилям.
- UI и скролл: используются общий DOM-клон, DOM-пути и относительная синхронизация с Axiom.

Сгенерированные Tailwind-классы GMGN не используются как селекторы.
