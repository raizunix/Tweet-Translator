# Аудит отказоустойчивости перевода

Актуально на 2026-09-04.

## Найденные причины отказов

1. Все публичные API запускались сразу для каждого блока твита. Это увеличивало расход анонимных
   квот и вероятность `429`.
2. После трёх ошибок все circuit breaker могли одновременно открыться. Следующий запрос завершался
   локальной ошибкой `No translation provider is currently available`, даже без контрольной пробы.
3. Lingva и публичные LibreTranslate-инстансы считались равнозначными Google, хотя их собственные
   проекты и сторонние библиотеки относят такие endpoints к нестабильным.
4. Отмена между созданием гонки и фактическим стартом провайдера могла пропустить событие `abort`.
5. Было только два практически полезных источника для `en→ru`: Google и MyMemory. Apertium не
   поддерживает эту прямую пару на публичном сервере.

## Что применено

- Добавлены независимые Bing web translator и TartuNLP.
- Вместо массового fan-out используется hedged race: Google стартует сразу; Bing, TartuNLP,
  MyMemory и нестабильные источники присоединяются только если ранний ответ задержался.
- Зеркала одного проекта также запускаются ступенчато, а не все одновременно.
- Первый валидный результат отменяет активные и ещё не стартовавшие запросы.
- Circuit breaker использует экспоненциальный cooldown. Когда открыты все цепи, выбирается один
  recovery probe; пользователь больше не получает локальную ошибку об отсутствии провайдера.
- Добавлены три попытки с backoff, строгая проверка защитных маркеров и результата после их
  восстановления.
- Ошибки отдельных внешних сервисов больше не показываются пользователю как финальный диагноз.

## Сравнение с другими решениями

- [AnyLang / translate-tools](https://github.com/translate-tools/core) отделяет нестабильные
  Lingva, LibreTranslate, Yandex и Reverso от основных движков, предоставляет fallback translator,
  scheduler, cache и лимиты частоты запросов.
- [Immersive Script](https://github.com/plateaukao/immersive-script) ограничивает параллелизм,
  применяет rate limit, backoff, `Retry-After`, обновляет истёкший Bing token и повторяет запросы.
- [Translate Browser Extension](https://github.com/MikkoParkkola/translate-browser-extension)
  использует цепочку failover, session cache и опциональный локальный переводчик.
- [TartuNLP Translation API](https://api.tartunlp.ai/translation/docs) предоставляет публичный
  нейронный API; проверочный запрос `eng→rus` вернул успешный перевод во время аудита.

## Остаточный риск

Абсолютная доступность невозможна без собственного backend или локальной модели: все внешние
бесплатные web endpoints могут одновременно ограничить IP, изменить HTML/API либо стать
недоступными. Пользовательский proxy остаётся наиболее контролируемым последним резервом.
